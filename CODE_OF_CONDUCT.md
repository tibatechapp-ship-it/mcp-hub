# Code of Conduct

## Our pledge

We want participation in this project to be free of harassment for everyone,
regardless of experience level, background, identity or language.

## Expected behaviour

- Assume good faith. Ask a question before assuming malice.
- Critique code, not people. "This query will table-scan on 10k rows" is
  useful; "this is stupid" is not.
- Accept that maintainers may decline a change that does not fit the project's
  scope — a declined PR is not a personal judgement.
- Be patient with people writing in a second language.

## Unacceptable behaviour

Insults, harassment, discriminatory comments, sexualised attention, publishing
someone's private information, and sustained disruption of discussions.

## Scope

Issues, pull requests, discussions, and any space where someone represents the
project.

## Enforcement

Report problems to the maintainer via a private security advisory or by email
listed on the GitHub profile. Reports are handled confidentially. Maintainers
may warn, edit or delete comments, or block accounts, depending on severity and
repetition.
